Stream Deck Launcher 1.1.0-beta.1 is a **version 1 Linux x86_64 beta**, with native Steam integration. Real Steam Deck/Bazzite acceptance remains outstanding. This public repository starts with fresh beta history; earlier development history and releases remain in a private archive. These downloads were rebuilt from the clean source commit identified below.

The beta adds left-stick tile navigation with dead zones/hysteresis, diagonal locking and stable held repeat, retaining D-pad/A, keyboard and reconnect/replacement behavior. B closes Setup or asks before quitting; Menu/F1 opens Setup. While a supported external browser owns focus, B can raise the dashboard on X11/XWayland without changing or closing the browser. It uses the open launcher's normal Gamepad API, with no global keyboard hooks/input grabbing. Setup can disable it. Native Wayland return is unavailable; physical controller/Steam Input background delivery is unverified.

Archive/source installers and normal AppImage startup attempt **native Steam** shortcut creation. Quit Steam completely first. A running client produces a pending status; Setup provides Retry/account selection. Root aliases are deduplicated; one unique most-recent account can be selected automatically. Existing databases are backed up privately, validated and replaced transactionally with running-client/concurrent-change checks. Repeated setup updates only the owned shortcut, keeps its app ID and preserves unrelated games, custom launch options/working directories/artwork. AppImage shortcuts use the original file with `--appimage-extract-and-run` and a stable copied icon. Space/non-ASCII paths work; embedded double quotes/control characters produce an error.

**Flatpak Steam automatic shortcuts are unsupported with its default sandbox.** Those layouts are detected but their database is left untouched: a host path alone would not launch there. Native Steam is required for automatic integration in this beta. This is separate from supported Flatpak streaming browsers. No broad filesystem/session-bus permissions are added. Steam shortcuts are retained on uninstall; remove obsolete entries through Steam if desired.

Display-sleep prevention follows **browser-wide MPRIS playback**, replacing dashboard/child-process lifetime. Recognized Chromium, Google Chrome, Brave and Firefox command/Flatpak identities are matched explicitly. Exactly one inhibitor follows fresh `Playing`; pause, stop, player loss, bus/query errors, expired observations and app quit release it. Existing-browser handoff and delayed registration are supported. Bounded, non-overlapping polling reads application identity/playback state only: no titles, URLs, history or media metadata are requested/persisted. No debugging ports/extensions/new profiles are added. Other media tabs in that browser family can inhibit; exact launched-tab attribution is unavailable. Unknown wrappers/browsers without MPRIS show unsupported/off. Buffering follows the browser's report. Keep the launcher running for monitoring.

Includes isolated Node fallback tests, repair for a Node version probe that fails, and conservative persisted usage validation. Invalid roots/counts cannot break sorting or concatenate counts; valid nonnegative safe integers/zero/unknown keys remain. Unreadable history is preserved. Counts measure command starts, not successful login/playback; asynchronous rollback is observable only while the launcher runs.

Verify `SHA256SUMS` with `sha256sum --ignore-missing -c SHA256SUMS`. Extract the complete installer archive and run `./install.sh` in Desktop Mode. Electron/Node are included; an application-menu entry and native Steam setup are provided. Alternatively mark the AppImage executable and open it; it attempts Steam setup but creates no application-menu entry. Keep its file at the chosen path, reopening after moves to refresh its shortcut. Windows/macOS/ARM/musl Linux are unsupported by these artifacts.

Archive setup checks platform/native libraries, a real isolated Electron renderer, `gdbus`/the session bus and the selected browser before copying the app. The X11 probe preserves default/explicit authority paths without changing cookies/permissions. Missing supported browser Flatpaks/runtimes can be installed from Flathub for the current user; existing browsers are reused and repeat setup rechecks. AppImage browser setup offers Install/Quit and progress. Missing custom commands, unsupported Flatpaks and download failures are reported.

Host prerequisites: glibc Linux x86_64, Bash/core tools, `ldd`, compatible GTK 3/GLib/GIO/NSS/DBus/ATK/CUPS/DRM/GBM/ALSA/X11/Wayland libraries, a graphical session and native sandbox support. Playback needs `gdbus`/the user session bus; B-return needs `xprop`/X11 or XWayland foreground class/focus information. The Flatpak CLI must already exist for Flatpak browsers. Repair OS prerequisites with supported distribution tools. Browser installation needs network/disk space. Ordinary AppImage mounting requires FUSE before embedded checks can run; `--appimage-extract-and-run` or the archive avoids FUSE. No sudo/system package manager/privileged installation/security-setting changes are automated. The embedded desktop entry retains `AppRun --enable-sandbox %U` with no silent sandbox-disabling fallback.

Automated checks include the full suite/lint, source/first-run smoke, packaged dependency CLI, archive install/upgrade/uninstall/repeat, visible windows/preload/IPC/navigation, usage persistence and AppImage dispatch. The integrated feature check uses real Electron/a real isolated Gio-D-Bus service, synthetic controller/X11 identities and disposable Steam files. Package checks observe actual packaged MPRIS transitions and inspect automatically created/reused shortcuts. Node/browser/Flatpak installation tests use fixtures, not real installations. Virtual-X11 tests explicitly use `--no-sandbox --disable-gpu` as container exceptions, which do not establish native sandbox support.

**Not validated on real Steam Deck/Bazzite:** native sandbox startup, Gaming Mode, physical controllers/Steam Input/background Gamepad delivery, native Wayland, real Steam shortcut acceptance, live browser downloads, sign-in/login persistence, DRM/Widevine/codecs and service playback. Profiles remain external/reused. Passing fixtures does not establish every streaming service works. See TESTING.md and the exact workflow link below.

Legacy source folders/profiles/settings/Volta/Node are preserved. The archive backs up the exact shared menu entry, refuses unknown/symlinked app directories and replaces only its owned installation. Old source data is not imported/swept; keep custom data outside the owned app directory. Old source uninstallers can follow the shared shortcut and delete the new app: use the installed release's uninstaller. Settings/profiles/backups/Steam shortcuts remain. Refresh imported entries retaining v1.0.7's `--no-sandbox`.
